# Init AI Docs

维护让 AI 按任务找到当前规则的中文项目文档。总图负责导航，模块入口负责路由，专题保存细节，ChangeLog 保存历史。只处理用户请求的范围。

## 选择工作模式

| 请求 | 行为 | 按需参考 |
|---|---|---|
| 初始化导航 | 根据真实项目结构建立必要文档 | [文档层次](references/document-layout.md) |
| 增量维护 | 更新受影响规则及必要索引，不全量扫描 | 仅在新增层次时读文档层次 |
| 冲突或体量审计 | 只读检查，输出问题、证据和处理建议 | [审计与迁移](references/audit-and-migration.md) |
| 拆分、去重、优化 | 明确归属后迁移，核对完整性与导航 | 两份参考文档 |
| 仅出方案 | 完成只读分析和具体方案，不写文件 | 与方案有关的参考 |

保持现有技能名和调用方式。不要因提到文档就扩展成全项目整理，也不要默认加载所有参考文件。

## 先缩小读取范围

1. 定位用户指定的仓库、文档路径和适用项目规则；检查当前差异，保护无关未提交内容。
2. 优先用 `rg --files` 列文件，先看 UTF-8 字节数、标题和索引，再读相关章节。路径不存在时核对真实目录，不悄悄创建相似目录。
3. 从总图进入命中模块，再进入专题；跨域才追加协议、配置或共享契约。README 仅提供其实际记载的事实，模板内容不能证明业务或运行流程。
4. 历史日志和 ADR 默认不读，仅在追溯、回归或任务明确依赖时读取。只读脚本扫描不会要求把全文载入模型上下文。

## 文档归属与默认预算

| 层次 | 默认位置 | 职责 | 预算 |
|---|---|---|---|
| 总入口 | `Doc/AI_Understanding.md` | 身份、任务路由、目录概览、全局边界 | ≤8 KiB |
| 已拆分模块入口 | `Doc/Modules/<module>.md` | 职责、核心调用链、专题导航 | ≤4 KiB |
| 业务专题或未拆分模块 | `Doc/Modules/<module>/<topic>.md` 等 | 入口、行为、参数、绑定、异常与验收状态 | 通常 8～20 KiB；>24 KiB 评估拆分 |
| 历史 | `Doc/ChangeLog/` | 已发生的变更 | 不作为默认阅读入口 |

预算按 UTF-8 字节计算，不是 token 数；项目明确规则可覆盖默认值。短文不必填满预算。超限先检查职责与重复，不机械按行数切割；无法合理拆分时说明原因，不牺牲完整语义。文档层次与命名取决于真实模块，不复制某次项目的文件数量或分类。

- 一项完整规则只设一个主文档，其他位置用短摘要和链接。协议字段归协议文档，配置定义归配置文档，行为与组件接入归业务专题；按项目已有职责调整。
- 更新原条目，不在末尾追加“本条覆盖前述描述”。确认事实、当前策略、已知问题、未知项就近分类，不把历史步骤写成当前事实。
- 保留精确字段、数值、适用条件、失败路径和未验收记录；未知仍写 `UNKNOWN`，不由名称或存在某个文件推断功能已接入。
- 项目文档使用中文，读写显式 UTF-8。保留有效既有结构，避免无关重排与整份重写；拆分任务只替换被迁出的细节和必要索引。

## 执行与授权

是否需要确认，遵循当前项目规则、用户请求及已有授权，不增加通用审批关卡。只读审计不产生修改；已确认方案内的必要迁移与同步继续完成。

发现文档与实现冲突时，源码只能证明当前实现，不能自行取代业务约定。核对双方位置与上下文；不能判定时记录冲突、暂停该条修正，并继续不依赖该结论的工作。中文乱码应重新显式 UTF-8 读取，未恢复前不据此写补丁。需要扩大范围或越过未授权资源边界时说明具体原因。

拆分前建立临时迁移清单：原条目 → 新位置 / 合并依据 / 删除原因。跨段规则连同条件一起迁移；相似文本仅供人工复核，不能自动删重。详细核对方法见审计与迁移参考。

执行后按项目规则记录当月 ChangeLog；只读审计不写执行记录。日志仅记真实改动，ADR 仅用于实际架构决策。只有存在且明确需要同步的源目录与安装目录才同步技能；当前生效目录已经是唯一版本时直接更新，不创建第二套副本。

## 检查与交付

必要时运行本技能的只读脚本，路径相对于本技能目录：

```text
python scripts/audit_docs.py /path/to/project/Doc
python scripts/audit_docs.py /path/to/project/Doc --scope Modules/chat.md --json
```

全量审计检查导航可达性；局部 `--scope` 只检查指定文件，不据此判定孤立专题。默认排除 ChangeLog 和 Decisions；预算参数可覆盖。脚本只向 stdout 输出，不修改文档，不读取图片内容，不访问网络。报告限制和参数见 [审计与迁移](references/audit-and-migration.md)。

修改后检查 UTF-8、相对链接、入口可达性、体量、旧规则残留、迁移去向和最终差异。项目有 Git 时检查受影响文件 diff；否则与修改前快照比较。机械检查不能证明语义无冲突，仍需核对业务规则与证据。不要默认执行项目测试、构建或运行验收。

交付简述实际修改范围、入口与专题体量、修正的冲突、保留的 UNKNOWN、检查结果和未完成项。仅在确有相关操作时报告日志、ADR 或技能同步，不输出无关检查清单。
